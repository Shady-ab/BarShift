# Credits and Asset Notes

BarShift: Mix & Serve was built as a student Unity project.

- Gameplay code: project source in `Assets/Scripts`
- UI visuals: generated from Unity uGUI shapes and project-defined colours
- Customer cards: generated in UI from colours and initials
- Sound effects: procedurally generated at runtime in `GameAudio.cs`
- GDD gameplay mockup: created specifically for this project

The playable project does not require third-party art, music or sound files.
